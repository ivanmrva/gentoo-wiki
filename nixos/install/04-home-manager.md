# home-manager

Part of [Phase B](02-flake-repository.md). User configuration lives in
`home/`. `common.nix` also runs standalone on Gentoo from
[Phase 0](00-prepare-on-gentoo.md#03-home-manager-on-gentoo-starting-now),
so it is proven before install day.

## home/gnome.nix

GNOME settings are generated from the live Gentoo system, not typed:
`dconf dump / | dconf2nix > home/dconf.nix`
([0.7](00-prepare-on-gentoo.md#07-export-checklist-before-the-wipe)). Prune
it: remove window state and `nm-applet/eap` entries. What it carries over
includes night light, 2 fixed workspaces, Alt-Tab by window, `Super+k` and
`Super+F4`, battery percentage, clock with seconds and weekday, touchpad,
Nautilus list/tree view, the Light theme, trash/temp cleanup after 30 days,
break reminders, the Claude Desktop shortcut, and the extension settings.

```nix
{ lib, pkgs, ... }: {
  imports = [ ./dconf.nix ];              # generated by dconf2nix, pruned

  programs.gnome-shell = {
    enable = true;
    extensions = with pkgs.gnomeExtensions; [
      { package = vitals; }
      { package = clipboard-indicator; }
      { package = hide-top-bar; }
      { package = removable-drive-menu; }   # "drive-menu"; check the attribute name
    ];
  };

  dconf.settings = {
    "org/gnome/desktop/input-sources".sources = [
      (lib.hm.gvariant.mkTuple [ "xkb" "us" ])
      (lib.hm.gvariant.mkTuple [ "xkb" "ch" ])    # Swiss German
    ];
    # Never auto-suspend on AC (GNOME default: suspend after 15 min). Replaces
    # Gentoo's inhibit-sleep-on-ac udev rule + service.
    "org/gnome/settings-daemon/plugins/power" = {
      sleep-inactive-ac-type = "nothing";
      sleep-inactive-battery-type = "suspend";
    };
  };

  # Default apps, from ~/.config/mimeapps.list
  xdg.mimeApps = {
    enable = true;
    defaultApplications = {
      "x-scheme-handler/http"   = "google-chrome.desktop";
      "x-scheme-handler/https"  = "google-chrome.desktop";
      "x-scheme-handler/mailto" = "google-chrome.desktop";   # Gmail
      "image/jpeg" = "org.gnome.gThumb.desktop";
      "image/png"  = "org.gnome.gThumb.desktop";
      "application/json" = "org.gnome.TextEditor.desktop";
      # office formats → office-viewer.desktop (once ported)
    };
  };
}
```

If `dconf.nix` sets one of the keys above to a different value, evaluation
fails with a conflict. Remove the duplicate from `dconf.nix` so each key is
defined once.

## B14c. home/drive-sync.nix (Google Drive two-way sync)

Linux has no official Google Drive client. rclone's `bisync` is the
established open-source two-way sync. It is marked beta upstream, hence the
safety options below. Only selected folders are synced, never whole volumes.

```nix
{ pkgs, ... }:
let
  rclone = "${pkgs.rclone}/bin/rclone";
  bisync = local: remote: ''
    ${rclone} bisync "$HOME/${local}" "${remote}" \
      --workdir "$HOME/.local/state/rclone-bisync" \
      --check-access --resilient --recover --max-lock 2m \
      --conflict-resolve newer --max-delete 25 \
      --create-empty-src-dirs --drive-skip-gdocs -v \
      --password-command "${pkgs.libsecret}/bin/secret-tool lookup service rclone"
  '';
in {
  home.packages = [ pkgs.rclone pkgs.libnotify pkgs.libsecret ];

  systemd.user.services.drive-sync = {
    Unit = {
      Description = "Two-way sync of selected folders with Google Drive";
      OnFailure = [ "drive-sync-failed.service" ];
    };
    Service = {
      Type = "oneshot";
      ExecStart = toString (pkgs.writeShellScript "drive-sync" ''
        set -eu
        # skip on metered connections (phone hotspot): NetworkManager Metered 1=yes 3=guess-yes
        m=$(${pkgs.systemd}/bin/busctl get-property org.freedesktop.NetworkManager \
           /org/freedesktop/NetworkManager org.freedesktop.NetworkManager Metered | cut -d' ' -f2)
        { [ "$m" = 1 ] || [ "$m" = 3 ]; } && exit 0
        ${bisync "Personal/Drive" "gdrive:Personal"}
        ${bisync "Work/Drive" "gdrive:Work"}
        # add further pairs here, e.g. Media/Pictures/Shared -> gdrive:Photos
      '');
    };
  };
  systemd.user.timers.drive-sync = {
    Timer = { OnCalendar = "*:0/15"; Persistent = true; };
    Install.WantedBy = [ "timers.target" ];
  };
  systemd.user.services.drive-sync-failed.Service = {
    Type = "oneshot";
    ExecStart = "${pkgs.libnotify}/bin/notify-send -u critical "
      + "'Google Drive sync failed' 'journalctl --user -u drive-sync'";
  };
}
```

1. `--workdir` keeps bisync's state outside `~/.cache` (a carve-out that is
   not backed up); losing it forces a full resync.
1. `--check-access` aborts unless a marker file `RCLONE_TEST` exists on both
   sides, so an empty or unmounted folder cannot wipe the Drive side.
   `--max-delete 25` aborts if more than 25 % of files would be deleted.
1. `--conflict-resolve newer` keeps the newer version. The other is kept
   with a conflict suffix, so nothing is lost silently. Google Docs/Sheets
   are skipped (they are not files).

> [!NOTE]
> **Client data (decision: synced):** `~/Work/Drive` is synced like
> `~/Personal/Drive`, so its files are stored unencrypted in a personal
> Google account. If client contracts or data-protection duties (nDSG) ever
> require it, two options keep the sync: a Google Workspace business account
> with Google's data processing terms, or an rclone crypt remote for `~/Work`
> (encrypted on Drive, but then readable only through rclone).

Gentoo has three rclone remotes (`personal`, `ivoiq`, `gdrive`). Restore the
user `rclone.conf` from restic rather than recreating them, then check the
quota occasionally with `rclone about gdrive:`.
